# 🌾 Kheti Hisab — Farm, Expense & Profit Manager

**Kheti Hisab — Farm, Expense & Profit Manager** is an offline-first, single-file HTML web application built for Indian farmers and agricultural partnerships. It works directly in any mobile or desktop browser without requiring internet access or a backend server, helping you manage crop expenses, bag-weight sales, trader advances, and final profit/loss calculations in one place.

*(ભારતીય ખેડૂતો અને ભાગીદારી ખેતી માટે બનાવેલી ઓફલાઇન-ફર્સ્ટ સિંગલ-ફાઇલ HTML વેબ એપ, જેમાં ખેતર, પાક ખર્ચ, ભાગીદારી/ઈજારો, ઓકડા વજન વેચાણ અને ચોખ્ખા નફા-નુકસાનનો સંપૂર્ણ હિસાબ રાખી શકાય છે.)*

### ✨ Key Features
- **🌱 Farm, Field & Crop Management:** Organize multiple farm owners, fields, and seasonal crops cleanly.
- **💸 Cultivation Expense Tracking:** Record seed, fertilizer, pesticide, labor, irrigation, and equipment expenses by crop and date.
- **🤝 Partnership & Ijaro Accounting:** Automatically split expenses, revenue, and net profit/loss across partners or fixed-lease (Ijaro) arrangements.
- **⚖️ Bag-Weight (Okda) Sales & Deductions:** Fast bag-weight entry with automatic calculation of total weight, bardaan, chharan, maund-kg conversion, and vatav.
- **🏪 Trader Advance Ledger & Printable Bills:** Track advance payments from traders and generate clean, print-ready bills and summaries.
- **💾 100% Offline & JSON Backup:** All records are saved locally in browser `localStorage` with one-click JSON export and restore.

### 🚀 How to Use
1. Open `index.html` directly in your browser or visit the hosted **GitHub Pages** link.
2. On Android Chrome, tap **Add to Home Screen** to install and use it like a native mobile app.
